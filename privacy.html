The workbook

The authorized owner’s workbook is organized by day and meal. A row can contain the name when a name is available, the meal, the room when it is available, the invitation language, the rating, and an optional note. It can also contain the Riyadh times for the meal reference, the scheduled invitation, the sent invitation, the rating, and the completed note. This page does not publish those rows.

Google Drive hosts the file. WhatsApp delivers the invitations and the owner-only notifications. Those companies process the data required for that hosting and delivery.

Google user data

The application requests one Google scope, https://www.googleapis.com/auth/drive.file. It uses that scope to create and update the meal-feedback workbook in the connected account, and to confirm that the connected account is almatherhr@gmail.com. It does not request access to the rest of Drive.

Google user data received through this scope is used only to provide that private workbook to the authorized owner. It is not sold. It is not used for advertising, retargeting, or creditworthiness. The owner and people the owner authorizes can view the workbook.

This is the application’s Limited Use disclosure. The Google policy is published at Google API Services User Data Policy, Limited Use.

The OAuth client tokens are kept on the application server and are not placed in the workbook. Only almatherhr@gmail.com is the authorized account.

The owner can revoke the connection from Google Account connections. Revoking access stops future updates from the application. It does not delete the workbook already stored in Google Drive. The owner can delete or share that file from Drive.
